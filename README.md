# Gym Business Revenue & Growth Analysis

## Overview
Analysis of gym business data including revenue trends, member behaviour, and attendance patterns.

## Tools Used
- Python (Pandas, Matplotlib)
- Power BI
- Excel

## Project Structure
- `gym_data.xlsx` - Dataset (150 members, 12 months)
- `01_data_generation.ipynb` - Data generation
- `02_revenue_analysis.ipynb` - Revenue analysis & charts
- `03_member_analysis.ipynb` - Member & churn analysis
- `04_attendance_analysis.ipynb` - Attendance analysis

## Key Insights
- Premium members contribute highest revenue
- January and June have highest new member joins
- Morning slots are most popular (45% of visits)
- Churn rate is highest among Basic plan members
